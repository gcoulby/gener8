# Shortcuts

## Keyboard

| Key | |
|---|---|
| <kbd>space</kbd> | Start or pause audio. Hold it and drag to pan. |
| <kbd>g</kbd> | Open these docs. |
| <kbd>h</kbd> or <kbd>?</kbd> | Quick help. |
| <kbd>tab</kbd> / <kbd>shift</kbd>+<kbd>tab</kbd> | Cycle through everything under the cursor, including field edges. |
| <kbd>esc</kbd> | Close menus and panels, cancel a timeline preview, clear the selection. |
| <kbd>delete</kbd> | Remove the selection. |
| <kbd>⌘D</kbd> | Duplicate the selection. |
| <kbd>[</kbd> <kbd>]</kbd> | Layer down / up. |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Nudge a semitone along the pitch axis (<kbd>shift</kbd>: an octave). Where no map sets pitch, <kbd>↑</kbd> <kbd>↓</kbd> change the sound's own note. |
| <kbd>m</kbd> | Cycle motion: orbit, drift, path, bounce, none. |
| <kbd>b</kbd> | Toggle breathe. |
| <kbd>n</kbd> | Show or hide the minimap. |
| <kbd>c</kbd> | Capture the last 30 seconds. |
| <kbd>shift</kbd>+<kbd>C</kbd> | Render the patch from a fresh start, up to an hour. |
| <kbd>t</kbd> | Tap tempo. |
| <kbd>r</kbd> | Random patch. |
| <kbd>⌘S</kbd> / <kbd>⌘O</kbd> | Save / open a patch file. |
| <kbd>+</kbd> <kbd>−</kbd> <kbd>0</kbd> | Zoom in, zoom out, reset the view. |
| <kbd>shift</kbd>+<kbd>D</kbd> <kbd>T</kbd> <kbd>R</kbd> <kbd>X</kbd> | The ambient, tape, rhythmic and stress examples. |

## Mouse and trackpad

| | |
|---|---|
| drag from the palette | Place a sound or field. |
| drag an object | Move it, along with anything that follows it. |
| <kbd>alt</kbd>-drag | Duplicate and move. |
| drag empty canvas | Pan. Right-drag and two-finger scroll pan too. |
| <kbd>⌘</kbd>-scroll or pinch | Zoom. |
| double-click a sound | Open its internals. |
| <kbd>alt</kbd>-scroll | Halve or double the selected object's motion period. |
| drag or scroll a value chip | Change it. |
| click or drag in the minimap | Move the view. Scroll over it to zoom. |

## Touch

Tap ▶ to start. **+** opens the palette. Pinch to zoom, and drag empty space to pan. Tap a selected object again to step down through what's under it. Double-tap a sound for its internals.
